# Veda Technology Business & Services Website

## Project Description
A professional, responsive business website for Veda Technology that presents technology programs, internship and training opportunities, IT and digital services, company information, FAQs, and contact details.

## Features
- Responsive homepage with hero section
- About Us section
- Technology programs displayed using reusable cards
- IT and digital services section
- Internship and training information
- Interactive FAQ section
- Responsive navigation with mobile menu
- Contact form with frontend validation
- Newsletter form with frontend validation
- Automatic footer year
- Basic SEO meta description
- Responsive layouts for different screen sizes

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## How to Run the Project
1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Test the navigation, FAQ, contact form, and newsletter form.

## Important Notes
- Contact and newsletter forms currently perform frontend validation only.
- Messages are not sent and newsletter subscriptions are not stored without a backend or external service.
- Verify company contact details and statistics before publishing.
- Replace placeholder social media links with official links.

## Project Objective
To develop a multi-section business website while applying responsive web design, reusable UI components, JavaScript interactions, SEO fundamentals, and professional UI practices.
